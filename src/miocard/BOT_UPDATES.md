# Обновления бота «Миокард»

Текущая версия: 0.9.0

## 0.9.0

- Модераторы могут разослать сообщение всем пользователям бота командой /announce.
- Модераторы могут остановить бота командой /shutdown: перед остановкой пользователям придёт уведомление.

## 0.8.0

- Перед ответом бот обдумывает запись, а не описывает её сразу: разбор стал внимательнее к деталям.
- Бот ищет не только преждевременные сокращения, но и паузы, выпадения и признаки нарушенного проведения.
- Изменения ST и зубца T проверяются по всем группам отведений, включая взаимные изменения в противоположных.
- Добавлена проверка признаков, которые нельзя пропускать: предвозбуждение, блокады, удлинённый QT, низкий вольтаж.
- Увеличенные фрагменты записи теперь действительно детальнее, а не просто вырезаны из уменьшенной копии.
- Подозрительные места отмечаются как требующие проверки, а не выдаются за подтверждённые находки.
- Разбор доступен на более новой модели Opus.

## 0.7.1

- Анализ распознаёт измеряемые паттерны P mitrale и P pulmonale.
- Для признаков гипертрофии левого и правого желудочков применяются отдельные критерии амплитуд R и S по конкретным отведениям.
- Если масштаб или сетка не позволяют надёжно измерить зубцы, бот не делает вывод о гипертрофии только по высокому вольтажу.

## 0.7.0

- Обмен с системой анализа стал компактнее и расходует меньше исходящих токенов.
- Оформление и содержание пользовательского отчёта при этом не изменились.
- Бот продолжает понимать ранее сохранённые результаты старого формата.

## 0.6.4

- Под размеченной ЭКГ теперь указано, какое наблюдение соответствует каждой отметке.
- Расшифровка отметок показывается рядом с изображением и в Telegram, и в PDF.

## 0.6.3

- Модераторы и Мария могут скачать текущий рабочий промпт командой /prompt.
- Промпт отправляется полностью, без сокращений, отдельным текстовым документом.

## 0.6.2

- PDF-отчёт прикрепляется к основному сообщению с результатом анализа.
- При наличии отметок пользователь также получает отдельную размеченную ЭКГ.

## 0.6.1

- Модератор получает карточку журнала и PDF-отчёт одним сообщением.
- ЭКГ, разметка и полный ответ находятся внутри приложенного документа.

## 0.6.0

- Через /support можно отправить модераторам текст, пересланное сообщение, фотографию или документ.
- Под каждым результатом ЭКГ появились кнопки для сообщения об ошибке анализа или неверном результате.
- Ответ пользователя возвращается именно тому модератору, который ему написал.
- Обычные сообщения вне начатого обращения модераторам не пересылаются.

## 0.5.1

- Сообщение «Что изменилось» показывается каждому пользователю только один раз для версии.
- Полную историю изменений теперь можно открыть командой /updates.

## 0.5.0

- Пользователь получает аккуратно оформленный PDF с полным разбором и копией ЭКГ.
- При наличии отметок размеченная ЭКГ добавляется непосредственно в PDF.
- Исходная ЭКГ и карточка журнала приходят модератору одним сообщением.
- Название модели в пользовательском PDF не отображается.

## 0.4.2

- В журнале анализа часовой пояс теперь отображается понятно и без лишних знаков вопроса.

## 0.4.1

- Повторный локальный запуск автоматически завершает предыдущий экземпляр бота.
- Бот больше не создаёт конфликт Telegram из-за двух локальных процессов с одним токеном.

## 0.4.0

- Модераторы получают журнал каждого анализа с пользователем, временем и расходом.
- В тестовом режиме журнал также содержит исходную ЭКГ, контекст и точный ответ бота.
- Для продакшена содержимое ЭКГ и ответов можно отключить, сохранив только статистику.

## 0.3.0

- Повторные проверки увеличенных фрагментов стали экономнее без уменьшения их количества.
- Полный медицинский разбор теперь формируется только один раз.
- Статистика расхода стала подробнее и понятнее.

## 0.2.1

- Бот сравнивает признаки фибрилляции и трепетания предсердий без приоритета только из-за частоты пульса.
- Панорамные фотографии ЭКГ автоматически очищаются от больших пустых полей перед анализом.
- Сетка и шум на снимке больше не считаются достаточным признаком трепетания предсердий.
- При нехватке обязательных признаков бот показывает осторожный дифференциальный вывод вместо уверенного диагноза.

## 0.2.0

- Бот лучше замечает отдельные преждевременные комплексы по всей записи.
- Поздняя часть ЭКГ проверяется отдельно, чтобы не пропускать менее заметные нарушения.
- Улучшено различение синусового ритма и возможного трепетания предсердий.
- При неудачной попытке анализ автоматически повторяется.

## Правило версий

Версия записывается как `A.B.C`:

- `A` повышается только при масштабных изменениях продукта; `B` и `C` сбрасываются в ноль.
- `B` повышается при серьёзных изменениях кода; `C` сбрасывается в ноль.
- `C` повышается при изменениях промпта, небольших улучшениях и исправлениях.

Для каждой новой версии добавляется отдельный раздел с кратким описанием изменений для пользователей.
